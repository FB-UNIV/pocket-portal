# Security policy

## Supported versions

Only the latest release gets security fixes. Upgrade to it before
reporting, if you can.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through GitHub:
**Security → Report a vulnerability** on this repository (private
vulnerability reporting). Include what you found, how to reproduce it, and
the version or commit.

You'll get an acknowledgement, and a fix or a decision, as fast as a
volunteer-maintained project allows. Once a fix is released, the advisory is
published with credit to you unless you'd rather stay anonymous.

## Scope

The portal and everything in this repository: the image and the reference
compose file, plus the [Helm chart](https://github.com/FB-UNIV/pocket-portal-helm). PocketID itself is out of scope; report its
issues [upstream](https://github.com/pocket-id/pocket-id/security).

Known, accepted limitations are listed under
[Known operational issues](docs/RUNBOOK.md#known-operational-issues).
